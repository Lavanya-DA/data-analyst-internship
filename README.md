# Data Analyst Internship — Sysslan IT Solutions

A practical Data Analyst internship project focused on cleaning, validating, analyzing, and visualizing train schedule data using Python and Pandas.

## 📌 Project Overview

This repository contains the work completed during my Data Analyst Internship at **Sysslan IT Solutions**.

The project follows an end-to-end data analysis workflow, starting from raw train schedule data and progressing through data review, preprocessing, quality validation, exploratory analysis, visualization, and a final capstone analysis.

## 🎯 Objectives

- Review and understand the structure of the raw dataset
- Clean and preprocess train schedule data
- Identify and validate data quality issues
- Perform exploratory data analysis
- Analyze train routes, stations, timings, and journey durations
- Create visualizations to communicate findings
- Build a final analysis workflow using Pandas

## 🛠️ Tools & Technologies

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Jupyter Notebook**
- **CSV Data**

## 🔄 Project Workflow

### 1. Basic Data Review
Inspected the dataset structure, columns, data types, missing values, and initial records.

### 2. Data Processing
Performed data cleaning and preprocessing to prepare the dataset for analysis.

### 3. Data Quality Checks
Validated the processed dataset by checking for missing values, duplicates, inconsistencies, and other quality issues.

### 4. Analysis & Visualization
Analyzed train schedules, stations, routes, timings, and journey-related patterns using Pandas and visualizations.

### 5. Advanced Analysis
Performed additional analysis to derive meaningful insights from the cleaned train schedule data.

### 6. Final Capstone
Combined the analysis workflow into a final capstone project with validated data, analysis, and visual outputs.

## 📊 Key Analysis Areas

- Train and station distribution
- Station traffic patterns
- Train routes
- Arrival and departure timings
- Journey duration
- Route classification
- Train schedule patterns
